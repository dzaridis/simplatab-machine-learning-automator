# Example: subgroups of adult-onset diabetes

Synthetic data for the **Clustering** automator (generated by `make_example.py`), after the five subgroups of
Ahlqvist et al., *Lancet Diabetes Endocrinol* 2018. Upload `Train.csv` (and optionally `Test.csv`) on the
automator's upload page; both are also downloadable from that page.

| Column | Role | Meaning |
|---|---|---|
| `ID` | identifier | patient (P0001-P0800) |
| `Age` | feature | age at diagnosis (years) |
| `Sex` | feature (categorical) | F / M |
| `BMI` | feature | body mass index (kg/m²) |
| `HbA1c` | feature | glycated haemoglobin (mmol/mol) |
| `HOMA2_B` | feature | beta-cell function (%) |
| `HOMA2_IR` | feature | insulin resistance (2% missing: imputed) |
| `GADA` | feature (categorical) | glutamic acid decarboxylase antibodies: Positive / Negative |
| `Systolic_BP` | feature | systolic blood pressure (mmHg): the same in every subgroup |
| `Target` | labels (optional) | SAID, SIDD, SIRD, MOD or MARD; only used to evaluate the clusters |

- **Train.csv**: 600 patients; **Test.csv**: 200 other patients.
- With `Target`, the clusters are compared with the subgroups (ARI, AMI, purity, matched accuracy...); delete the
  column to try the unsupervised setting (internal metrics only).

Suggested settings: the number of clusters set to the number of classes (5), or chosen automatically between 2 and 8.
The Gaussian mixture and the deep networks should recover the subgroups best (ARI around 0.6-0.8); `GADA`,
`HOMA2_IR`, `HOMA2_B`, `BMI`, `Age` and `HbA1c` should explain the clusters, `Systolic_BP` hardly at all.
