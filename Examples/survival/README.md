# Example: overall survival after colorectal cancer surgery

Synthetic data for the **Survival Analysis** automator (generated by `make_example.py`). Upload `Train.csv` and
`Test.csv` on the automator's upload page; both are also downloadable from that page.

| Column | Role | Meaning |
|---|---|---|
| `ID` | identifier | patient |
| `Time` | follow-up | months from surgery to death or last follow-up |
| `Event` | event indicator | 1 death, 0 censored (alive at the last follow-up) |
| `Age`, `Sex`, `Stage` (I-IV), `Grade` (1-3), `Tumour_size_mm`, `CEA`, `ECOG`, `Positive_nodes`, `Adjuvant_chemo` | features | |
| `BMI` | feature | no effect on survival |

- **Train.csv**: 800 patients (about half censored); **Test.csv**: 300 other patients.
- The effects are not all proportional: age has a U-shaped effect and chemotherapy helps stage III patients only,
  which the boosting and neural models can capture.

Suggested settings: horizons 12, 24 and 48 months. Every model should beat the Kaplan-Meier reference (C-index around
0.7), and stage, ECOG, CEA and age should come first in the permutation importance, BMI last.
