    Data requirements

    • Two zip files, at most {{ max_gb }} GB each
    • One folder per class; the folder names are the class names
    • The same class folders in both zips, at least two classes
    • DICOM (.dcm or no extension, compressed and multi-frame), NIfTI (.nii, .nii.gz), PNG (8 or 16-bit), JPEG, BMP, TIFF
    • Sub-folders (e.g. one per patient) are allowed: every image file is one sample
    • Keep all the images of a patient in the same zip, otherwise the test metrics are optimistic
    • 3D volumes are reduced to one 2D image (middle slice or maximum intensity projection)
