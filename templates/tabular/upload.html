    Data requirements

    • CSV files with a header row and the same feature columns
    • A numeric column named Target in both files
    • Binary: 0 / 1, where 1 is the positive class
    • Multiclass: consecutive integers 0, 1, …, K-1
    • Numeric and categorical features are both supported
    • An optional ID (or patient_id) column is used as identifier, not as a feature
    • Rows with missing values are removed
    • Categorical columns whose values differ between the two files are dropped
