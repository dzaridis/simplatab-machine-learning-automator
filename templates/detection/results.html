About these metrics
IoU
Intersection over union of a detected box and a true box{% if info.dim == 3 %} (of their volumes){% endif %}: 1 is a perfect overlap. A detection is correct when its IoU with an unmatched true box of the same class reaches the threshold.
mAP
Mean average precision over the classes and the IoU thresholds {{ '0.50 to 0.95 (COCO)' if info.dim == 2 else '0.10 to 0.50 (3D boxes overlap less for the same quality)' }}; {{ 'AP50 and AP75' if info.dim == 2 else 'AP10, AP25 and AP50' }} at a single threshold. The average precision summarises the precision-recall curve, whatever the score threshold.
{{ 'AR100' if info.dim == 2 else 'AR' }}
Average recall: the share of true boxes found with up to 100 detections per {{ unit }}.
FROC CPM
Mean sensitivity at 1/8, 1/4, 1/2, 1, 2, 4 and 8 false positives per {{ unit }} (IoU ≥ {{ info.main_iou }}), as in the LUNA16 challenge.
Precision, recall, F1
Of the boxes above the score threshold chosen on the validation {{ unit }}s (best F1).
{{ unit | capitalize }} sensitivity / specificity
An {{ unit }} is positive when it has true boxes and predicted positive when a detection reaches the threshold.
