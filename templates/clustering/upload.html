    Data requirements

    • One row per sample (e.g. a patient), a header row, comma separated
    • Feature columns: numeric or categorical (text); missing values are imputed
    • ID (or patient_id): optional identifier, never a feature
    • Target: optional class labels. With it, the clusters are checked against the classes (ARI, AMI, purity…); without it, the clustering is evaluated by internal metrics only. The labels never influence the clusters.
    • Test.csv (optional): same feature columns; its samples are assigned to the clusters found on Train.csv
