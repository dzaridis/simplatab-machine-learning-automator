About these metrics
Dice
Overlap of the predicted and true masks of a class: twice the shared {{ 'voxels' if info.dim == 3 else 'pixels' }} over the sum of both masks, from 0 to 1 (perfect). Each metric is computed per case and class, then averaged; a class absent from both the reference and the prediction of a case is left out.
IoU
Intersection over union (Jaccard index): shared {{ 'voxels' if info.dim == 3 else 'pixels' }} over the union of both masks.
HD95
95th percentile of the distances between the boundaries of the predicted and true masks, in {{ 'millimetres' if info.unit == 'mm' else 'pixels' }}: the largest boundary error, ignoring the worst 5%. Lower is better; undefined when either mask is empty.
ASSD
Average symmetric surface distance between both boundaries, in {{ 'millimetres' if info.unit == 'mm' else 'pixels' }}. Lower is better.
Sensitivity
Share of the true mask that is predicted (recall).
Precision
Share of the predicted mask that is true.
